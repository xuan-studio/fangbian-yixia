# 方便一下：真实流程与视觉审查

日期：2026-08-15  
环境：本地开发服务 `http://localhost:3000/`，Chrome 桌面视口

## 结论

核心演示路径可用。公开厕所数据、组合筛选、详情、四级紧急降级、娱乐型健康观察和红旗安全分流均通过。小红书优质榜继续保持真实空状态，新抓取内容只进入候选证据层。

## 本轮发现并修复

1. **3D 地图容器高度为 0**：MapLibre 自带样式覆盖了绝对定位规则，导致页面看起来像有地图框但 3D 图层实际没有尺寸。现改为更具体的 `.map-frame .map-canvas`，并锁定宽高 100%。
2. **3D 柱体在当前 Chrome/WebGL 下不显示**：高度过渡动画触发 GPU 时间查询错误。移除非必要动画后，941 个柱体正常绘制。
3. **筛选后详情仍显示筛选外的厕所**：当原选中项不在新结果中时，详情现在自动切换到首个命中项；空结果时清空详情。

## 视觉审查

- 信息层级清晰：左侧任务参数、中间 3D 态势、右侧选中设施，三列关系一眼可读。
- 荧光绿只用于关键动作与 24 小时点，青色用于公开数据，金色预留优质榜，语义稳定。
- 紧急面板直接覆盖地图工作区，不遮挡左右数据依据，适合现场演示。
- 健康弹窗的红旗状态采用红色边框和警示文本，和娱乐态明显区分。
- 当前在线底图在受限网络中会降级为概念地图，这是有意设计；不影响筛选、详情和紧急推荐。

## 保留项

- 小红书原帖图片文字和评论尚未完整读取，候选数据不得直接当正式评分。
- 当前路线距离是直线估算，不是步行导航。
- 公开数据的很多设施字段确实未知，界面继续显示“待核实”。
