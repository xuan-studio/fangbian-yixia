# 「方便一下」项目介绍

> 上海厕所 3D 情报地图：平时帮你发现值得去的厕所，着急时帮你最快找到能用的厕所。

## 一句话定位

「方便一下」把公开厕所数据、小红书优质厕所线索、用户现场反馈和 AI 结构化能力放到一张上海 3D 地图里，解决“厕所很多，但真正需要时不知道哪个能用、好不好用、具体在哪里”的问题。

项目口号：**以屎为镜，可以知天命！**

健康模块仅提供娱乐型观察和安全提醒，不提供医疗诊断。

## 为什么值得做

上海并不缺厕所点位，缺的是面向真实使用场景的厕所情报：

- 公开地图能告诉用户“附近可能有厕所”，但开放时间、蹲坐类型、无障碍设施和楼内位置经常缺失。
- 社交平台上有大量“宝藏厕所”内容，却是非结构化文字，难以搜索、比较和在地图上使用。
- 真正憋不住时，用户不需要一份完美榜单，而需要一个能持续降级、保证下一步行动的方案。
- 商场厕所不仅是成本中心，也可能成为体验、传播和到店打卡的入口。

## 产品方案

### 1. 上海厕所 3D 情报地图

- 展示 941 个 OpenStreetMap 上海公共厕所点。
- 使用亮色真实底图、3D 数据柱和上海离线概念轮廓。
- 支持行政区、开放信息、蹲厕、坐厕、无障碍、第三卫生间和数据来源筛选。
- 在线地图失败时自动降级，筛选、详情和紧急推荐仍可使用。

### 2. 小红书优质厕所榜单

- 当前已整理并匹配 12 个小红书榜单或专题场所。
- 榜单场所在地图上用金色 3D 柱展示。
- 平台证据观点、Mock 演示评论和用户现场评论分层显示，避免混淆来源。
- 商场坐标只代表场所或 POI；具体厕所楼层、方位和设施没有证据时继续显示“待核实”。

### 3. “憋不住了”四级降级找厕

系统根据当前位置或人民广场演示点，给出从理想到保底的四级方案：

1. 优先选择信息可信、距离较近且开放情况明确的厕所。
2. 放宽设施条件，优先保证可到达。
3. 放宽数据完整度，展示最近的公开厕所候选。
4. 数据不足时给出搜索范围和线下求助建议，避免流程中断。

当前距离为直线估算，不冒充精确步行导航；系统也不声称拥有实时排队数据。

### 4. AI 与社区共建

- AI 将用户自然语言中的楼层、方位、蹲厕、无障碍、开放状态等信息提取为结构化候选。
- 楼内位置需要 3 位独立用户确认后才能正式上线。
- 演示票和真实社区确认分开计数，含演示票的结果只能标记为“演示上线”。
- “厕所共建中心”支持多维评分、事实纠错、状态报告、新厕所投稿、多人验证和版本记录。

### 5. 娱乐型健康观察

- 用户可以记录排泄类型和文字描述，获得轻量、娱乐型趋势观察。
- 遇到便血、黑便、持续腹痛等红旗信号时停止娱乐判断，直接提示联系医生，必要时就医。
- 不做诊断，不把个体健康数据出售给商家；研究合作必须建立在明确同意和匿名汇总基础上。

## 典型演示故事

1. 打开全城地图：看到上海公开厕所覆盖，以及 12 个金色优质场所。
2. 使用区域与设施筛选：说明“未知不等于没有”，缺失字段保持待核实。
3. 点击一个小红书榜单场所：展示平台证据、Mock 评论和现场反馈的来源分层。
4. 演示楼内位置投稿：用户输入“5F 东南侧，靠近扶梯”，AI 自动提取结构化位置，3 人确认后才上线。
5. 点击“憋不住了”：展示四级降级推荐，证明产品在不完整数据下仍能帮助用户行动。
6. 输入一次普通排泄记录和一次红旗描述：展示娱乐观察与医疗安全边界。
7. 收尾到商业价值：厕所从基础设施变成商场体验、传播与运营数据入口。

## 商业价值

### 商场厕所体验 SaaS

为商场和商业集团提供清洁巡检、设施缺口、拥挤反馈、顾客评价和竞品对标，按门店或商圈订阅。

### 明确标注的推广位

商家可以购买“推广”展示，但推广不得影响紧急模式的距离、开放状态和可用性排序。

### 城市服务与运营合作

向园区、景区、交通枢纽和城市管理部门提供设施覆盖、无障碍缺口、数据新鲜度和服务半径分析。

### 自愿匿名的研究合作

在用户明确授权、匿名化和聚合处理的前提下，为公共健康或城市卫生研究提供趋势数据；不出售个体排泄记录，不宣称医学结论。

### “厕所目的地化”营销

用优质卫生间设计、打卡传播和场内动线运营，验证厕所能否帮助商场从“购物 Target”变成“到访 Target”。南京德基广场等案例目前只作为产品假设启发，正式路演中的经营数字仍需可靠来源支持。

## 技术与数据

- 前端：React 19、TypeScript、Vite/Vinext。
- 地图：MapLibre GL + deck.gl。
- 数据：本地 JSON，离线优先，不依赖账号或云端数据库。
- 公开厕所：OpenStreetMap，遵循 ODbL 署名。
- 统一数据结构：`app/types.ts`。
- JSON Schema：`public/data/toilet-record.schema.json`。
- 质量原则：未知字段使用 `null`；界面显示“待核实”；不把未知当成“无”。

## 30 秒项目介绍

「方便一下」是一张上海厕所 3D 情报地图。我们先用公开数据覆盖全城，再把小红书上的优质厕所内容变成可筛选的结构化榜单。真正着急时，系统不会假装数据完美，而是通过四级降级持续给出下一步选择。用户还可以补充商场厕所的楼层和方位，AI 自动结构化，经过 3 人确认后再上线。对用户，这是一个找厕所和发现宝藏厕所的工具；对商场，这是体验运营和到店传播的数据入口。
